# 可合法获取的唐诗古代注评资料包

本目录收录四种已经进入公有领域、并由中文维基文库开放录入的唐诗古代选本、诗话和评论资料。每种均提供 Markdown 与 JSON 两种格式。

## 文件清单

### 《唐诗纪事》

- `tang_shi_ji_shi.md`
- `tang_shi_ji_shi.json`
- 内容：序、目录及正文八十一卷，共83个章节
- 提取正文：457,260字
- 特点：兼载诗作、诗人生平、创作本事、逸闻和古代评论，是本资料包中覆盖最广的一种

### 《全唐诗话》

- `quan_tang_shi_hua.md`
- `quan_tang_shi_hua.json`
- 内容：序及正文六卷，共7个章节
- 提取正文：87,184字
- 特点：主要节录《唐诗纪事》，便于快速查阅；旧题尤袤撰，但编者归属存在争议

### 《唐诗镜》

- `tang_shi_jing.md`
- `tang_shi_jing.json`
- 内容：正文五十四卷
- 提取正文：319,293字
- 特点：明代陆时雍编选，保存大量短评、品第和审美判断

### 《唐诗品汇》附《唐诗拾遗》

- `tang_shi_pin_hui.md`
- `tang_shi_pin_hui.json`
- 内容：《唐诗品汇》九十卷、《唐诗拾遗》目录及正文十卷，共101个章节
- 提取正文：494,524字
- 特点：按初、盛、中、晚唐及诗体、品第编选；原序记载正编收5769首、《拾遗》增954首

`manifest.json`记录了各文件的章节数、字数和SHA-256校验值。

## JSON结构

每种书的JSON顶层包含：

- `metadata`：书名、作者、版本、来源、许可、章节数、字数和使用限制
- `chapters`：逐章对象数组
  - `index`：章节顺序
  - `title`：章节标题
  - `source_epub_entry`：维基文库导出包中的来源条目
  - `text`：正文

## 来源和许可

来源均为中文维基文库：

- [《唐诗纪事》（四部丛刊本）](https://zh.wikisource.org/wiki/唐詩紀事_(四部叢刊本))
- [《全唐诗话》](https://zh.wikisource.org/wiki/全唐詩話)
- [《唐诗镜》（四库全书本）](https://zh.wikisource.org/wiki/唐詩鏡_(四庫全書本))
- [《唐诗品汇》（四库全书本）](https://zh.wikisource.org/wiki/唐詩品彚_(四庫全書本))

古代原著已经进入公有领域；维基文库录入文字及本资料包中的转换文本依照 [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/) 使用。再分发或改编时应保留署名、来源链接及相同方式共享要求。

## 限制

- 这些是古代诗话、选本与古代评论，不是现代白话翻译，也不是《新修增订注释全唐诗》的现代校勘注释。
- 转换过程只删除网页导航、图片和站点界面，没有擅自校改正文。
- 开放录入可能存在OCR、标点、异体字、底本或断句错误，作学术引用时应回查影印底本。
- 《全唐诗话》与《唐诗纪事》有大量重合内容；资料包有意保留各书原貌，没有跨书去重。
