## 转换说明

- 通过 MediaWiki API 读取已经公开转录的页面，没有建立或使用本地 OCR 环境。
- 仅提取 `div.poem` 正文，保留页面显示的 `〈古注/校语〉` 边界，删除导航与样式。
- 每卷记录来源页面、页面修订号和源维基文本 SHA-256，便于复核。
- 开放录入可能有异体字、缺字、标点或底本问题；严肃引用应回查原页面和影印本。
