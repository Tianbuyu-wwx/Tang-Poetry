# 唐诗开放资料补充路线

> 最近核查：2026-07-22

网站的补充对象不只包括字词注释，也包括题解、创作本事、作者小传、校勘、句评、篇评、诗法分析和历代接受。自动挂接仍以“能够唯一对齐到一首诗”为底线，不用诗题或作者名强行猜配。

## 已接入

### 《唐诗鼓吹》（四库全书本）

- 状态：已下载十卷开放转录，并接入典籍页与诗作页。
- 内容：中晚唐七律为主；含作者小传、字词音义、典故出处、异文和郝天挺笺注。
- 本次结果：提取 1,692 条，命中 547 首；全站带内容诗作由 3,743 首增至 4,189 首。
- 来源：[中文维基文库《唐诗鼔吹》](https://zh.wikisource.org/wiki/唐詩鼔吹_(四庫全書本))。

## 本轮已完成的修改

### 数据与来源

- 新增 `docs/tang_commentaries_public_domain_3/`，保存《唐诗鼓吹》十卷 JSON、Markdown、README 和 manifest。
- 新增 `scripts/fetch_wikisource_tang_shi_gu_chui.py`：通过 MediaWiki API 读取公开转录文本，记录来源页面、修订号、时间戳和源文本 SHA-256；不安装或调用本地 OCR。
- `scripts/import_docs.py` 纳入第三批资料，并把《唐诗鼓吹》的 `〈古注〉` 按注释断点两侧诗句唯一匹配到诗作。
- 网站典籍从 12 部增至 **13 部 / 412 章**；正文保持 **57,674 首**、**3,656 位诗人**。

### 页面与交互

- 诗作页不再把所有古籍材料混称为“古籍注评”，现在分为：
  - “注释”：现有现代字词注释；
  - “古籍注释”：古注、校勘、典故和逐句说明；
  - “赏析”：现有现代赏析；
  - “古籍赏评”：古代选本的章法、风格、炼字和篇评。
- 古籍条目继续保留书名、原文和出处；无法唯一挂接的诗话、传记、本事仍留在典籍全文检索，不强行归给某首诗。
- 首页、关于页、典籍页的统计和说明同步更新；旧的 `test_js.js` 绝对路径也已改为按项目目录定位。

- 价值：一千首唐诗选本，适合补异文、篇名、作者归属和选本接受史。
- 当前判断：全文转录可用，但原书本身逐诗评注较少，对“有注解/赏析”的直接增量有限；暂不为了增加书目数量而接入。
- 来源：[中文维基文库《才调集》](https://zh.wikisource.org/wiki/才調集_(四庫全書本))。

## 接入原则

1. 古代原著须已进入公版；现代录入须有明确开放许可。
2. 现代版权期内的白话译注、鉴赏辞典和商业网站赏析只作为人工查证线索，不抓取、不改写后批量发布。
3. 逐句材料优先使用“注释断点两侧诗句唯一命中”；篇末评点还须同时对齐诗首和诗末。
4. 无法唯一归属的诗话、本事和传记保留在典籍全文检索，不自动挂到单诗页面。
5. 页面按“现代注释、古籍注释、现代赏析、古籍赏评”分栏，来源与许可随诗保留。
