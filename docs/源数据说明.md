## 与构建链的关系

```
[本文件所述源数据]                        ← 不入库，可再生
        │ scripts/import_docs.py（全量导入，仅本地跑）
        ▼
scripts/_work/poems-data.js              ← 入库，事实源（决策项，暂维持）
website/assets/js/{poets,sources}-data…
        │ scripts/build_curated.py（社员桥接，CI 跑）
        ▼
website/ 分片与索引 → verify_all 79 项门 → Pages 上线
```

- **日常投稿与建站**：只涉及下半段（CI 自动），不需要上段任何文件。
- **全量重导**（换语料底版、批注体系升级时）：先确认上表文件在本地存在，
  按 skill「6 步幂等构建链」顺序执行。
- `docs/curated/`、`docs/news/`、`docs/periodicals/`、`docs/lessons.json`
  是 CMS 投稿与社务内容的事实源，**始终入库**，与本文件所述源数据无关。
