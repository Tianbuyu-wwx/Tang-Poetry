# 唐诗公版注评资料包（二）

本目录是第二批可以合法取得并转换的唐诗古代注释、评论、传记与本事资料。八种书均提供完整 Markdown 和 JSON；合计157个章节，提取正文约1,646,876字。

## 核心注本

### 《御选唐诗》

- 文件：`yu_xuan_tang_shi.md`、`yu_xuan_tang_shi.json`
- 内容：提要、序及正文三十二卷
- 提取正文：1,022,255字
- 价值：本批最接近“逐句注释唐诗”的资料。按诗体选录唐诗，并逐句征引经史、前代诗文、地理和制度资料解释字词、典故与语源

### 《唐音癸签》

- 文件：`tang_yin_gui_qian.md`、`tang_yin_gui_qian.json`
- 内容：提要及正文三十三卷
- 提取正文：140,647字
- 价值：系统汇集唐诗体制、格律、历代评论、乐府、名物典故、诗坛逸事和唐诗书目

## 诗人传记与创作本事

### 《唐才子传》

- 文件：`tang_cai_zi_zhuan.md`、`tang_cai_zi_zhuan.json`
- 内容：四库提要及四库辑本八卷
- 提取正文：51,865字
- 价值：诗人生平、科第、交游、作品风格与文学评价
- 注意：这是《四库全书》辑本八卷，不等同于其他系统的十卷本

### 《本事诗》

- 文件：`ben_shi_shi.md`、`ben_shi_shi.json`
- 内容：情感、事感、高逸、怨愤、征异、征咎、嘲戏七类
- 提取正文：10,143字
- 价值：唐人记录诗歌创作背景与故事的重要原始材料

### 《云溪友议》

- 文件：`yun_xi_you_yi.md`、`yun_xi_you_yi.json`
- 内容：提要、原序及上中下三卷，共六十五条
- 提取正文：33,152字
- 价值：中晚唐诗坛掌故、逸篇和评论；属于“唐人说唐诗”的材料

### 《唐摭言》

- 文件：`tang_zhi_yan.md`、`tang_zhi_yan.json`
- 内容：提要及正文十五卷
- 提取正文：76,870字
- 价值：唐代科举、进士交游、诗人轶事和文坛环境

## 古代选评与诗法

### 《瀛奎律髓》

- 文件：`ying_kui_lv_sui.md`、`ying_kui_lv_sui.json`
- 内容：提要、原序及正文四十九卷
- 提取正文：283,591字
- 价值：分类选录唐宋五七言律诗，附大量背景、诗法、字句和优劣评论
- 注意：同时收录宋诗，不是纯唐诗集

### 《唐贤三昧集》

- 文件：`tang_xian_san_mei_ji.md`、`tang_xian_san_mei_ji.json`
- 内容：提要及正文上中下三卷
- 提取正文：28,353字
- 价值：王士禛以盛唐作品阐发“神韵”诗学，适合与《唐诗镜》等选本对读

## 格式与校验

JSON顶层包含 `metadata` 和 `chapters`；每章记录顺序、标题、维基文库导出条目和完整正文。`manifest.json`列出全部文件的章节数、字数及SHA-256。

## 限制

- 全部内容都是古代原著与古代注评，不包含现代出版社的受版权保护注释。
- 保留繁体字与文言文，没有自动翻译或擅自校改。
- 开放录入可能存在OCR、异体字、断句或底本问题；少量以图片表示的罕见字在纯文本转换中可能缺失。
- 用于学术引用时应回查维基文库原页面和影印底本。
