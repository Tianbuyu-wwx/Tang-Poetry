## 关于“完整注释本”的重要限制

这个 JSON **不是**陈贻焮主编的 2001 年《增订注释全唐诗》，也不是陈铁民、彭庆生主编的 2023 年《新修增订注释全唐诗》电子版。它只有极少量来源短注，不能当作完整学术注释本。

真正符合“全书校勘并逐诗注释”要求的是黄山书社 2023 年出版的《新修增订注释全唐诗》（全五册，ISBN `978-7-5461-7775-5`）。公开资料称其约 1,800 万字，新增注释一万余条，并订补作者小传和原有注释。该现代校注成果仍受版权保护，因此本次没有复制、OCR、抓取或打包其全文。

合法获取可通过出版社、图书馆馆藏或馆际互借。参考资料：

## 使用提示

该数据适合全文检索、自然语言处理、索引原型和个人阅读，但用于学术引用前应回查可靠纸本或影印底本。古代诗歌正文与现代标点、校勘、注释的权利状态并不相同；再分发时请同时保留来源与许可信息。
