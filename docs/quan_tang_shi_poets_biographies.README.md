## 匹配原则

先做繁简转换，再综合本名、别名、字号、僧名、隋唐五代年代范围与 CBDB 史料来源打分。只有唯一候选或来源分显著领先时才自动选择；无法判定的同名人物全部保留为候选。

## 版权边界

这里没有复制现代版权期内《新修增订注释全唐诗》《全唐诗作者小传补正》等书的整套正文。若某位作者只有 CBDB 数据，正文中的生平是由生卒年、籍贯、别名和仕历字段自动组织成的事实摘要；若仍无法核定，则明确写作“资料未详”，不编造生平。
